# Development Guide

## Local Setup

```sh
cp .env.example .env
go mod tidy
go generate ./ent
go run ./cmd/api
```

## Common Commands

```sh
make dev
make test
make migrate
make seed
make lint
make bootstrap-admin
```

`make seed` runs the unified JSON-based seeder for categories, products, flavors, and addons.

## Project Layers

- `internal/handlers`: HTTP transport layer — request decoding, response encoding, no business logic
- `internal/services`: business logic — order workflow, upload orchestration, tracking tokens, WhatsApp notifications, admin settings
- `internal/repository`: data access — Ent ORM queries/mutations only, no side effects
- `internal/validator`: input validation rules for request payloads
- `internal/middleware`: cross-cutting concerns — auth, roles, rate limiting, logging, recovery, security headers
- `internal/auth`: PocketBase wrapper for employee authentication and JWT validation

## Testing

Unit/package tests:

```sh
go test ./...
```

With race detector + coverage:

```sh
make test
# generates coverage.html
```

Integration scaffolding:

```sh
RUN_INTEGRATION=1 go test ./tests/integration/...
```

Optional env vars for integration auth tests:

- `INTEGRATION_BASE_URL`
- `INTEGRATION_ADMIN_EMAIL`
- `INTEGRATION_ADMIN_PASSWORD`

## Adding a New Entity

Follow the pattern used by `Order` as the reference:

1. **Schema** — `ent/schema/{entity}.go`: field definitions, edges, indexes via Ent DSL.
2. **Migration** — `migrations/000NNN_{entity}.sql`: generated by Ent after running `go generate ./ent` and applying via `make migrate`.
3. **Repository** — `internal/repository/{entity}_repo.go`: data access via Ent client.
4. **Service** — `internal/services/{entity}_service.go`: business logic and validations.
5. **Handler** — `internal/handlers/{entity}.go`: HTTP transport mapping, delegates to service.
6. **Validator** — `internal/validator/rules.go`: add `ValidateEntityCreate` / `ValidateEntityUpdate`.
7. **Router** — `internal/server/server.go`: register routes with appropriate middleware.
8. **Docs** — `docs/API.md`: document new endpoints.

## Coding Notes

- Put business logic in services, not handlers.
- Keep repositories Ent-specific and side-effect free.
- Use the validator package for all request payload checks.
- Regenerate Ent artifacts only via `go generate ./ent`.
- Rate limiter uses Redis when `REDIS_URL` is set; falls back to in-memory automatically.
- Security headers are applied globally — do not bypass them per-route without explicit justification.
