# API Documentation

> **Deprecated.** The API documentation is now served as an interactive OpenAPI-based UI.
>
> - **Interactive docs:** open **`/docs`** on a running server. Check the Scalar docs UI with your browser in http://localhost:8080/docs
> - **OpenAPI spec:** **`/openapi.yaml`** or **`/openapi.json`**
> - **Build artifact:** `api/openapi.yaml`
>
> See [`docs/GUIDE.md`](GUIDE.md) for endpoint patterns and the README for an overview.
